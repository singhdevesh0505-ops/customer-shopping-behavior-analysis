# 🛍️ Customer Shopping Behavior Analysis

An end-to-end **data analytics project** focused on understanding customer shopping behavior using **Python, SQL, and Power BI**.

This project demonstrates a complete analytics workflow — from data preparation and exploratory analysis to SQL-based business analysis and interactive dashboard development.

---

## 📌 Project Overview

Understanding customer purchasing behavior can help businesses identify patterns, evaluate customer segments, and make better data-driven decisions.

In this project, customer shopping data was analyzed using multiple data analytics tools to transform raw data into meaningful insights and an interactive business dashboard.

---

## 🎯 Project Objectives

The main objectives of this project were to:

* Understand customer shopping behavior
* Prepare and clean the dataset for analysis
* Perform exploratory data analysis using Python
* Answer business-oriented questions using SQL
* Build an interactive Power BI dashboard
* Convert analytical results into meaningful business insights

---

## 📊 Dataset

The dataset contains customer shopping behavior information.

**Dataset size:**

* **3,900 records**
* **18 attributes**

The dataset includes information related to customer demographics, shopping activity, purchasing behavior, and other customer-related characteristics.

### Data Preparation

The dataset was inspected and prepared before analysis.

The workflow included:

* Checking dataset structure
* Identifying missing values
* Reviewing data types
* Cleaning and preparing columns
* Preparing the data for further analysis

---

## 🐍 Python Analysis

Python was used for data preparation, exploratory analysis, and visualization.

### Libraries Used
